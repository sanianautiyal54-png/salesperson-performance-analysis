Salesperson Performance Analysis

Project Overview

This project focuses on analyzing salesperson performance using sales transaction data. The analysis was performed using Excel, SQL Server, and Power BI to understand sales trends, compare salesperson performance, and identify business insights.

Objectives

- Analyze total sales and order performance.
- Compare sales performance across salespeople.
- Identify top-performing salespeople.
- Analyze sales by product and region.
- Calculate average order value and total units sold.
- Understand sales trends over time.
- Compare salesperson performance across different regions.

Dataset

Dataset Name: "sample-sales.xlsx"

The dataset contains 240 rows and 8 columns:

- "order_id"
- "date"
- "product"
- "quantity"
- "unit_price"
- "total"
- "region"
- "salesperson"

Note: The dataset does not contain cost or profit information, so profit and profit margin analysis was not included.

Tools Used

- Microsoft Excel: Data review and preparation.
- SQL Server Management Studio (SSMS): Data analysis using SQL queries.
- Microsoft Power BI: Interactive dashboard creation and visualization.

Analysis Performed

- Total sales calculation.
- Total orders and units sold.
- Average order value analysis.
- Salesperson ranking based on total sales.
- Sales contribution by salesperson.
- Regional sales comparison.
- Product-wise sales analysis.
- Sales trend analysis over time.
- Salesperson performance comparison across regions.

Power BI Dashboard

Dashboard Name: Salesperson Performance Analysis Dashboard

The dashboard includes KPI cards and visualizations to present sales performance clearly.

Key visuals include:

- Total Sales
- Total Orders
- Total Units Sold
- Average Order Value
- Total Sales by Region
- Sales Contribution by Salesperson
- Sales Trend Over Time
- Salesperson Performance Ranking
- Sales by Product
- Salesperson Performance by Region

Key Business Questions

- Which salesperson generates the highest sales?
- Which region contributes the most to total sales?
- Which products generate the highest sales?
- How do sales change over time?
- How does salesperson performance vary across regions?
- What is the average order value?

Key Limitation

The dataset does not contain an actual sales target. Any sample target used in a Power BI gauge is for demonstration purposes only.

Conclusion

This project demonstrates an end-to-end data analysis workflow using Excel, SQL Server, and Power BI. It helps explore sales performance across salespeople, products, regions, and time while presenting the findings through an interactive dashboard.
